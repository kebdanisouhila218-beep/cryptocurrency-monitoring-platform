## 🔮 Prévisions

### Accéder aux prévisions

1. Cliquez sur **Analyses ▼**
2. Sélectionnez **Prévisions**

### Comment générer une prévision

1. **Choisir une crypto** : Utilisez le sélecteur (BTC, ETH, SOL, etc.)
2. **Choisir une période** : 30, 60 ou 90 jours
3. Cliquez sur **Générer la prévision**

### Interpréter les résultats

#### 📊 SMA (Moyenne Mobile Simple)
- **Définition** : Moyenne des prix sur la période
- **Confiance** : Fiabilité de la prédiction (0-1)
- **Utilisation** : Tendance à long terme

#### 📈 EMA (Moyenne Mobile Exponentielle)
- **Définition** : Moyenne pondérée (plus récente = plus importante)
- **Confiance** : Généralement plus fiable que SMA
- **Utilisation** : Tendance à court/moyen terme

#### 📉 Régression Linéaire
- **Définition** : Droite de tendance basée sur l'historique
- **Confiance** : Basée sur la corrélation linéaire
- **Utilisation** : Prédiction mathématique pure

#### 🎯 Prévision optimale
- **Définition** : Combinaison pondérée des 3 méthodes
- **Confiance** : Moyenne des confiances pondérées
- **Utilisation** : **La plus fiable** des prédictions

### Niveau de confiance
- **> 0.8** : Très fiable ✅
- **0.6-0.8** : Fiable ⚠️
- **< 0.6** : Peu fiable ❌

> ⚠️ **Avertissement** : Les prévisions sont des estimations basées sur l'historique. Ne basez pas vos décisions d'investissement uniquement sur ces prédictions.

## 🔬 Indicateurs Techniques

### Accéder aux indicateurs

1. Cliquez sur **Analyses ▼**
2. Sélectionnez **Indicateurs**

### Les indicateurs disponibles

#### 📊 RSI (Relative Strength Index)
- **Plage** : 0-100
- **Interprétation** :
  - **> 70** : Surachat (vendre potentiellement) 🔴
  - **30-70** : Neutre (maintenir) 🟡
  - **< 30** : Survente (acheter potentiellement) 🟢
- **Usage** : Identifier les points de retournement

#### 📈 MACD (Moving Average Convergence Divergence)
- **Composants** :
  - **MACD line** : Différence entre EMA 12 et 26
  - **Signal line** : EMA 9 du MACD
  - **Histogramme** : MACD - Signal
- **Signaux** :
  - **MACD > Signal** : Achat 🟢
  - **MACD < Signal** : Vente 🔴
- **Usage** : Identifier les changements de momentum

#### 📊 Bollinger Bands
- **Composants** :
  - **Bande supérieure** : SMA + 2 écart-types
  - **Bande moyenne** : SMA 20
  - **Bande inférieure** : SMA - 2 écart-types
- **Interprétation** :
  - **Prix > bande sup** : Surachat 🔴
  - **Prix < bande inf** : Survente 🟢
- **Usage** : Mesurer la volatilité

#### 🎯 Signal combiné
- **ACHAT** : Si 2+ indicateurs signalent l'achat 🟢
- **VENTE** : Si 2+ indicateurs signalent la vente 🔴
- **NEUTRE** : Si les signaux sont contradictoires 🟡

> 💡 **Conseil** : Utilisez toujours plusieurs indicateurs pour confirmer une tendance.

## 📈 Graphiques Chandeliers

### Accéder aux chandeliers

1. Cliquez sur **Analyses ▼**
2. Sélectionnez **Chandeliers**

### Comment lire un chandelier OHLC

```
    Haut (High)
      ┃
      ┃
Corps┃┃Ombre
      ┃
      ┃
    Bas (Low)
```

- **Open** : Prix d'ouverture
- **High** : Prix le plus haut
- **Low** : Prix le plus bas
- **Close** : Prix de clôture
- **Vert** : Hausse (Close > Open)
- **Rouge** : Baisse (Close < Open)

### Configurations

#### ⏱️ Intervalles
- **5m** : 5 minutes
- **15m** : 15 minutes
- **1h** : 1 heure
- **4h** : 4 heures
- **1d** : 1 jour

#### 📅 Périodes
- **1 jour** : Dernières 24h
- **3 jours** : Derniers 3 jours
- **7 jours** : Dernière semaine
- **14 jours** : Dernières 2 semaines
- **30 jours** : Dernier mois

#### 📊 Statistiques 24h
- **Plus haut** : Prix max sur 24h
- **Plus bas** : Prix min sur 24h
- **Volume** : Volume total échangé

## 🔔 Alertes

### Accéder aux alertes

1. Cliquez sur **Alertes** dans le menu

### Créer une alerte

1. Cliquez sur **➕ Créer une alerte**
2. Remplissez le formulaire :
   - **Cryptomonnaie** : Choisissez dans la liste (BTC, ETH, etc.)
   - **Prix cible** : Prix qui déclenchera l'alerte
   - **Type d'alerte** :
     - **Au-dessus** : Alert quand le prix dépasse le cible
     - **En-dessous** : Alert quand le prix passe sous le cible
3. Cliquez sur **Créer l'alerte**

#### Exemple
- **Crypto** : BTC
- **Prix cible** : 100 000 $
- **Type** : Au-dessus
- **Résultat** : Vous serez alerté quand le BTC dépassera 100 000 $

### Gérer les alertes

#### ✅ Activer/Désactiver
- Cliquez sur l'interrupteur pour activer/désactiver une alerte
- Les alertes désactivées ne génèrent pas de notifications

#### 🗑️ Supprimer
- Cliquez sur l'icône 🗑️ pour supprimer une alerte
- Confirmation requise

#### 📝 Modifier
- Cliquez sur l'icône ✏️ pour modifier le prix ou le type

### Notifications

#### 📧 Email
- Vous recevez un email quand une alerte se déclenche
- Sujet : "🔔 Alert CryptoTracker - [Crypto] a atteint [Prix]"

#### 💬 Discord
- Si vous avez configuré un webhook Discord
- Message formaté avec toutes les informations
- Testez votre webhook dans les paramètres du profil

## 💼 Portfolio Virtuel

### Accéder au portfolio

1. Cliquez sur **Portfolio Virtuel** dans le menu

### Vue d'ensemble

Le portfolio virtuel vous permet de **simuler des achats/ventes** sans risque réel.

### Créer un portfolio

1. Cliquez sur **➕ Créer un Portfolio**
2. Donnez un nom à votre portfolio
3. Cliquez sur **Créer**

### Acheter une crypto

1. Dans votre portfolio, cliquez sur **Acheter**
2. Sélectionnez la cryptomonnaie
3. Entrez :
   - **Quantité** : Nombre d'unités à acheter
   - **Prix** : Prix par unité (automatiquement rempli)
4. Cliquez sur **Confirmer l'achat**

### Vendre une crypto

1. Dans votre portfolio, cliquez sur **Vendre**
2. Sélectionnez la cryptomonnaie à vendre
3. Entrez la quantité
4. Cliquez sur **Confirmer la vente**

### Vue du portfolio

#### 📊 Statistiques globales
- **Valeur actuelle** : Valeur totale de votre portfolio
- **Investi** : Total de vos investissements
- **Profit/Loss** : Plus ou moins-value en $
- **Profit/Loss %** : Pourcentage de gain/perte
- **Cryptos détenues** : Nombre de cryptomonnaies différentes
- **Date de création** : Quand vous avez créé le portfolio

#### 📋 Positions
Pour chaque crypto détenue :
- **Quantité** : Nombre d'unités
- **Prix moyen** : Prix moyen d'achat
- **Valeur actuelle** : Valeur au prix actuel
- **P&L** : Plus/moins-value pour cette position

#### 📜 Historique
- **Transactions** : Liste de tous vos achats/ventes
- **Date** : Quand la transaction a eu lieu
- **Type** : Achat ou vente
- **Montant** : Total de la transaction

## 💡 Conseils d'utilisation

### 🔄 Actualisation régulière
- **Prix** : Se mettent à jour toutes les minutes automatiquement
- **Prévisions** : Basées sur les dernières données disponibles
- **Alertes** : Vérifiées toutes les 5 minutes

### ⚠️ Limitations des prévisions
- Les prévisions sont basées sur l'**historique**
- Elles ne tiennent pas compte des **événements imprévus**
- Utilisez-les comme **indication**, pas comme certitude

### 🔬 Utiliser plusieurs indicateurs
- Ne vous fiez pas à un seul indicateur
- **Confirmez** les tendances avec plusieurs outils
- **RSI + MACD + Bollinger** = Analyse plus robuste

### 🎯 Simulation avant investissement
- Utilisez le **portfolio virtuel** pour tester vos stratégies
- **Suivez vos performances** sans risque réel
- **Apprenez** des erreurs sans perdre d'argent

### 📱 Utilisation mobile

- **Actualisez** manuellement sur mobile pour les dernières données
- **Signets** : Ajoutez la page à vos favoris pour un accès rapide

## 🆘 Dépannage

### Problèmes courants

#### 🔄 Données qui ne s'actualisent pas
- **Solution** : Cliquez sur **Actualiser** manuellement
- **Cause** : Parfois le cache retient d'anciennes données

#### 🔔 Alertes qui ne se déclenchent pas
- **Vérifiez** : L'alerte est bien **active**
- **Vérifiez** : Votre email/Discord est bien configuré
- **Solution** : Testez avec une alerte à un prix proche

#### 💼 Portfolio qui ne se calcule pas
- **Solution** : Actualisez la page
- **Cause** : Les prix peuvent mettre quelques secondes à se mettre à jour

#### 📊 Graphiques qui ne s'affichent pas
- **Solution** : Vérifiez votre connexion internet
- **Alternative** : Essayez un autre navigateur
