# 🎯 POURQUOI J'AI UTILISÉ CHAQUE TECHNOLOGIE

---

## 📱 Frontend

**React** → Interface moderne avec composants réutilisables qui se mettent à jour sans recharger la page

---

## ⚙️ Backend

**FastAPI** → API Python ultra-rapide avec documentation auto-générée et validation des données intégrée

---

## 🗄️ Base de données

**MongoDB** → Base NoSQL flexible, pas de schéma fixe, parfaite pour les données qui changent souvent comme les prix crypto

---

## 🔄 Cache

**Redis** → Cache mémoire ultra-rapide pour stocker les sessions et les tâches en attente

---

## 📋 Tâches

**Celery** → Exécute des tâches en arrière-plan (collecte des prix toutes les minutes sans bloquer l'application)

---

## 🐳 Conteneurisation

**Docker** → Emballe l'application avec toutes ses dépendances, fonctionne pareil sur n'importe quel ordinateur

---

## 📊 Monitoring

**Prometheus** → Collecte les métriques (CPU, RAM, requêtes) toutes les 15 secondes

**Grafana** → Affiche les métriques en graphiques temps réel pour surveiller la santé de l'application

---

## 🔐 Sécurité

**JWT** → Tokens d'authentification sécurisés qui expirent après 30 minutes

**Argon2** → Hash des mots de passe plus sûr que bcrypt, avec salt unique par utilisateur

---

## 📈 Tests

**pytest** → Tests unitaires et intégration pour vérifier que le code fonctionne

**Locust** → Tests de performance pour simuler 100 utilisateurs simultanés

**Trivy** → Scan de sécurité des images Docker

---

## 🚀 CI/CD

**GitHub Actions** → Tests automatiques à chaque push, build et déploiement continu

---

## 📊 Visualisation

**Recharts** → Bibliothèque React pour créer des graphiques interactifs (chandeliers, prévisions)

---

## 🌐 API Externe

**CoinPaprika** → API gratuite et fiable pour récupérer les prix des cryptomonnaies en temps réel
