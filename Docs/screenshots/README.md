## 📐 Spécifications

- **Format** : PNG
- **Résolution** : 1920x1080 (desktop) ou 375x667 (mobile)
- **Qualité** : Haute résolution
- **Taille max** : 500 KB par image

---

## 🛠️ Comment capturer

### Windows
- `Win + Shift + S` : Capture d'écran sélective
- `Print Screen` : Capture plein écran

### Mac
- `Cmd + Shift + 4` : Capture sélective
- `Cmd + Shift + 3` : Capture plein écran

### Chrome DevTools
1. `F12` pour ouvrir DevTools
2. `Ctrl + Shift + P` → "Capture screenshot"
3. Choisir "Capture full size screenshot"
